# Hani's Egypt Journeys

Build a high-end, editorial portfolio website for a freelance digital designer and developer named “Tayseer Mohamed.” The design should feel like a precise, contemporary creative studio: bold, minimal, dark, grid-led, and highly typographic.
Visual direction:
- Use a near-black background: #0D0D0D.
- Use thin charcoal-gray grid lines and borders throughout.
- Alternate a few full-width sections with a soft off-white background: #E8E8E6.
- Use crisp white text, muted gray secondary text, and restrained warm-red imagery accents.
- Typography should be clean and confident: large uppercase sans-serif headlines with tight tracking, paired with small uppercase mono-style labels for metadata and captions.
- Avoid rounded cards, gradients, glass effects, bright colors, and generic SaaS layouts.
- Use sharp rectangular frames, editorial spacing, intentional asymmetry, and a visible modular 4-column grid on desktop.
- Add tiny “+” corner marks at important grid intersections as a recurring detail.
- Make the experience smooth and premium with subtle fade/slide reveals, hover image zoom, and refined transitions.
Build a single-page responsive portfolio with these sections:

Technical requirements:
- Fully responsive: convert the desktop grid into a clear stacked layout on mobile without horizontal scrolling.
- Use semantic HTML, accessible labels, keyboard-friendly accordion controls, and visible focus states.
- Implement smooth scroll navigation.
- Use subtle motion only: fade-up sections, slight image scale on hover, line/button hover transitions.
- Use placeholder images that can be easily replaced.
- Build this as a polished production-quality portfolio, not a template-style landing page.
